📘 Lesson 1: โครงสร้าง HTML

🧠 ลองนึกภาพแบบนี้

การเขียน HTML เหมือนกับการสร้าง “บ้าน 1 หลัง” 🏠

  • <html> = บ้านทั้งหลัง
  • <head> = สมอง (ข้อมูลเบื้องหลัง เช่น title)
  • <body> = ตัวบ้านที่เราเห็น
<html> ← บ้านทั้งหลัง 🏠
  <head></head> ← สมอง 🧠
  <body>Hello World</body> ← สิ่งที่คนเห็น 👀
</html>

💡 เข้าใจง่าย ๆ

สิ่งที่แสดงบนหน้าเว็บจริง ๆ คือ <body> เท่านั้น!

ถ้าเขียน Hello World ใน body → คนจะเห็นข้อความนี้

🎯 ภารกิจ

สร้างโครงสร้าง HTML และให้มีคำว่า Hello World อยู่ใน <body>
