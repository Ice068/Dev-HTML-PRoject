📊 Lesson 11: Table

🧠 ลองนึกภาพ

Table = ตารางข้อมูลแบบมีโครงสร้างซ้อนกัน 3 ชั้น เหมือนตารางเรียนหรือชีตคำนวณ: ตัวตาราง → แถวแนวนอน → ช่องข้อมูลแต่ละช่อง

🗺️ แผนภาพแนวคิด (ไม่ใช่เฉลยโค้ด)
[เปิดตารางทั้งตาราง (Table)]
  [เปิดแถวแนวนอน (Table Row)]
    [ช่องข้อมูลที่ 1 (Table Data)] ... [/ช่องข้อมูล]
    [ช่องข้อมูลที่ 2 (Table Data)] ... [/ช่องข้อมูล]
  [ปิดแถวแนวนอน]
[ปิดตารางทั้งตาราง]

💡 ลำดับชั้น 3 ส่วนประกอบ

  • ชั้นนอก (Table) = กรอบของตารางทั้งหมด
  • ชั้นกลาง (Table Row) = แถวแนวนอนในตาราง
  • ชั้นในสุด (Table Data) = ช่องข้อมูลแต่ละเซลล์ภายในแถว

🎯 ภารกิจ

สร้างตารางที่มีข้อมูล HTML และ CSS อยู่ในช่องข้อมูลของตาราง
